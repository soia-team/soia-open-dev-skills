# AI Provider 适配验收

仅在新增或修改 AI Provider 接口、上下文转换、用量返回时使用；不是通用 adapter 门禁。

先确认接口承诺，再选择本次受影响项：

- 上下文：system、消息顺序、多轮消息、tool call/result 是否完整传递；用包含这些内容的真实 fixture 核对输出，不能只检查字段存在。
- 用量：调用方能否区分计量、订阅与未知；缺失量不伪装成零，计费语义不靠模型名称猜测。
- 类型：公共类型有唯一归属，避免复制上层类型或 shadow enum。
- 消费者：至少沿一条真实下游路径验证新增行为；流式输出、取消和错误只在受影响时补测。

调用付费服务或写入远端需单独授权。离线 fixture 只能证明转换契约，不能声称线上凭据、模型访问或真实账单已验证。
