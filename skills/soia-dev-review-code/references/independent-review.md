# 多视角审查（仅明确要求 panel 时）

一次独立评审直接按 SKILL.md 执行；本文件只在用户或项目明确要求双评估/panel 时读取。自动收到一个 review 任务不是追加 panel 的授权。

## 两个视角

- A：在固定候选上判断规格符合性、正确性与范围内风险。
- B：在同一候选上运行相关确定性检查，保留命令、退出码和实际输出；机械检测不能代替行为与规格判断。
- 需要隔离判断时，A/B 各自只拿原始输入，在完成前不共享彼此结论；综合时合并一致项、核验单侧发现、剔除有依据的误报。

## 调用与证据

同宿主使用内置 subagent；外部 CLI 才走 dispatch。所需审核者资格由用户/项目政策决定，不把模型家族或执行体数量写成所有项目的固定标准。同一实际模型不得冒充异模型独立审核；真实模型未知时标未验证。

记录实际完成的视角、审核者与模型证据；只有所需视角缺失时写 DEGRADED 及原因。不能把一个未要求 panel 的单次审核标为降级。

## 交付与停止

给出范围、候选指纹、建议、问题位置及未验证项。全程只读，检查缓存放临时目录；没有新候选/证据不复跑，不继续递归派单。审查建议不是修改、合并、发布或风险豁免许可。

双视角概念参考 pbakaus/impeccable 的 critique 工作流；本技能仅按明确需求启用，不继承其默认工作量。
